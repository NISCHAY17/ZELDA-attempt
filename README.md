🗡️ About the Game A simple Zelda-inspired action game designed for a quick ~5-minute playthrough. Explore, fight, and experiment with abilities in a small, fast-paced experience.

🎯 Objective Defeat all enemies, cross the river, and defeat the boss.

🎮 How to Play

🧭 Movement W / A / S / D → Move your character Mouse → Aim / control direction Hold Ctrl → Run (faster movement) Movement is relative to the camera

⚔️ Combat & Abilities Left Click → Attack / use ability Right Click (hold) → Block / defend Q → Switch weapon E → Switch spell

⚠️ Note: Attacks and spells consume stamina/energy. You can’t spam everything — there are limits.

🦘 Actions Space → Jump (costs stamina)

🏰 Dungeon Interaction Walk into a dungeon door to enter Walk into the exit to leave

⚠️ Known issues: Expect bugs. Some interactions may feel inconsistent.
